# Security

Foxbridge is experimental. Review the data-handling and deployment limitations in the README before using it with confidential information.

Do not include live secrets, real customer data or exploit details in a public issue. If the repository offers GitHub's **Report a vulnerability** action, use it for a private report. Otherwise ask the maintainer for a private reporting channel without disclosing the sensitive details publicly. No response-time guarantee is provided.

If a credential is accidentally committed, revoke or rotate it with its issuer. Removing it from the current tree does not remove it from Git history, clones or caches.
